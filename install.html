導入方法

Kenma データパックの導入手順です。

必要なファイル

  • KubeJS データパックをダウンロード

手順

  1. modを導入できる環境にするために CurseForge を導入してください、curse forge 導入方法 で検索するとサイトがたくさんあります
  2. CurseForge から Forge 47.4.10 の Minecraft プロファイルを作成し、前ページの導入mod解説からmodを導入後、実際にマイクラを起動します

  3. curseforge/minecraft/Instances/作ったプロファイル フォルダを開き、 作成したプロファイルの中身のkube.jsのファイルをダウンロードしたファイルに置き換えます

  4. CurseForge から再度プロファイルを起動し、Minecraft を起動すれば完成です
